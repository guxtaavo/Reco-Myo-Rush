# Reco-Myo-Rush

Reco-Myo-Rush is a project currently under development.

The main idea is to use the **Myo Armband** to identify hand and arm gestures through its **8 EMG sensors**. These sensors capture muscle activity, which can then be processed and used for gesture recognition.

## Project Goal

The goal of this project is to explore gesture detection based on EMG signals collected from the Myo Armband.

## Notes

This repository is a work in progress, and new features and improvements will be added over time.
